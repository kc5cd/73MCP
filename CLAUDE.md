## Git workflow

- Never put a Claude session link (`https://claude.ai/code/session_...`) or any other
  internal/session-identifying URL in a commit message or PR description. A
  `Co-Authored-By:` trailer is fine on its own.
- Keep commit messages short — 2-3 sentences at most. Put extended rationale in the PR
  description instead.
- Never `git push` unless explicitly asked that turn — not even "helpfully."
